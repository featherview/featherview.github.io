Featherview

A fast, keyboard-driven image viewer for the Mac, with batch conversion.

In early development · macOS 14 Sonoma or later

Open one image, flip through the folder

  • Opens instantly and shows every image in the folder with the arrow keys
  • JPEG, PNG, HEIC, WebP, TIFF, GIF and camera RAW, upright and colour-managed
  • Lossless rotation for JPEG, HEIC and TIFF
  • Batch convert, resize and rename, never overwriting a file
  • EXIF info panel; delete moves to the Trash
  • Native: Mac menus, full screen, Finder “Open With”, drag and drop, Dark Mode

Fast by design

Speed is the feature. Featherview is built so the first image is on screen in under 300 ms, the next one appears with no visible delay, and a folder of 10,000 files opens without the window ever freezing.

Free and open source

Native Swift. The source opens up as the first release gets close. Follow along on GitHub.

Made by Joachim Rütter. Featherview is an independent project and not affiliated with any other image viewer.
